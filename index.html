Tentang Saya

Halo! Saya Muhammad Ryan Hidayat, mahasiswa Teknik Informatika di Universitas Bina Insani yang memiliki ketertarikan mendalam pada pengembangan web dan rekayasa perangkat lunak. Sejak awal kuliah, saya aktif belajar membangun aplikasi berbasis web — mulai dari antarmuka pengguna yang responsif dengan HTML, CSS, dan JavaScript, hingga logika sisi server menggunakan Python dan PHP. Saya percaya bahwa kode yang baik bukan hanya kode yang berjalan, tetapi kode yang mudah dibaca, dipelihara, dan dikembangkan oleh tim. Di luar kelas, saya senang mengerjakan proyek pribadi, berkontribusi pada komunitas, dan terus memperbarui pemahaman saya tentang teknologi terkini. Saya juga tertarik pada bidang keamanan aplikasi web dan praktik pengembangan perangkat lunak yang terstruktur. Ketika tidak sedang menulis kode, saya biasanya membaca dokumentasi teknis, mengikuti kursus daring, atau berdiskusi dengan rekan-rekan tentang solusi terbaik untuk masalah pemrograman sehari-hari.

Universitas: Universitas Bina Insani — Teknik Informatika

Angkatan: 2023

Tujuan Karir: Menjadi software engineer full-stack yang mampu membangun produk digital berdampak, dengan spesialisasi pada pengembangan web modern dan praktik rekayasa perangkat lunak yang berkualitas tinggi.
